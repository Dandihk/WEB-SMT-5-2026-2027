# 1. Overview (Brand & Style)

### A. Brand Identity
**SoundHoregSafe** adalah platform pemetaan interaktif real-time dan peringatan dini bahaya tingkat kebisingan event *sound horeg* di Kabupaten Pati. Aplikasi ini didesain khusus untuk membantu warga—terutama orang tua yang membawa anak balita—mengetahui lokasi event dan radius zona aman agar terhindar dari kerusakan pendengaran.

- **Karakter Visual (Tone & Mood):**
  - **Informatif & Siaga (*Alert-Driven*):** Menyampaikan tingkat bahaya secara langsung, intuitif, dan cepat dipahami.
  - **Modern & Responsif (*Mobile-First*):** Dioptimalkan untuk diakses di smartphone oleh warga yang sedang di jalan atau bepergian.
  - **Terpercaya & Bersih (*Clean & High-Legibility*):** Tampilan tidak sibuk (cluttered) agar data peta dan radius terlihat jelas tanpa halangan.

### B. Gaya Desain (Visual Theme)
- **Modern Map-Centric UI & Radar Aesthetics:** Menggabungkan peta full-screen dengan elemen antarmuka melayang (*floating cards & bottom sheets*).
- **Zone Layering:** Menggunakan lingkaran radius transparan berkode warna (*color-coded overlay*) di atas canvas peta (Leaflet.js/Mapbox).

# 3. Typography (Tipografi)

### A. Font Family
- **Font Utama (Headings & UI Controls):** `Plus Jakarta Sans` (Google Font - bersih, modern, mudah dibaca di layar HP).
- **Font Tubuh & Peta (Body & Map Labels):** `Inter` atau `System-UI` (optimasi legibilitas angka desibel dan koordinat).

### B. Font Scale & Hierarchy

| Role / Tag | CSS Variable | Ukuran (rem / px) | Weight | Kegunaan Utama |
| :--- | :--- | :--- | :--- | :--- |
| **Title / Hero (`<h1>`)** | `--fs-h1` | `1.75rem` (28px) | Bold (700) | Judul header aplikasi / Modal utama |
| **Section Header (`<h2>`)**| `--fs-h2` | `1.25rem` (20px) | Semi-Bold (600)| Judul card detail event & form |
| **Card Subtitle (`<h3>`)** | `--fs-h3` | `1.00rem` (16px) | Semi-Bold (600)| Nama event di popup peta |
| **Body Text (`<p>`)** | `--fs-body` | `0.938rem` (15px)| Regular (400) | Deskripsi event, petunjuk rute aman |
| **Badge / Label (`<small>`)**|`--fs-small`| `0.813rem` (13px)| Medium (500) | Label status (Active/Pending), dB |

```css

  line-height: 1.5;
}

h1, h2, h3, .ui-heading {
```

# 4. Layout & Spacing (Tata Letak & Jarak)

### A. Layout System (Map-First Overlay Architecture)
Karena SoundHoregSafe adalah aplikasi peta interaktif, layout tidak menggunakan halaman grid artikel konvensional, melainkan **Full-Viewport Canvas with Floating UI Overlays**:

- **Map Canvas:** `100vw` x `100vh` (Leaflet.js map layer memenuhi layar).
- **Floating Top Bar:** Bar pencarian alamat/kecamatan & filter status melayang di atas peta (`z-index: 1000`).
- **Floating Action Button (FAB):** Tombol bulat "+ Lapor Event" melayang di sudut kanan bawah (`z-index: 1000`).
- **Mobile Bottom Sheet:** Panel menggeser dari bawah untuk menampilkan detail event yang dipilih dari pin peta.

### B. Spacing Scale (8px Grid System)

```css
:root {
  --space-2xs: 4px;   /* Jarak antar ikon desibel & angka */
  --space-xs:  8px;   /* Gap antar badge status */
  --space-sm:  12px;  /* Padding internal button kecil */
  --space-md:  16px;  /* Padding card & input form */
  --space-lg:  24px;  /* Spacing antar section modal */
  --space-xl:  32px;  /* Jarak floating UI dari tepi layar */
}
```

# 5. Elevation & Depth (Elevasi & Bayangan)

Elevasi sangat krusial untuk memisahkan peta dasar (*background*) dengan kontrol interaktif (*floating UI*).

| Level Elevasi | CSS Variable | Shadow Value | Implementasi di SoundHoregSafe |
| :--- | :--- | :--- | :--- |
| **Flat (Level 0)** | - | `none` | Canvas Peta, Tile Layer |
| **Low (Level 1)** | `--shadow-sm` | `0 2px 4px rgba(0,0,0,0.08)` | Radius Circle Stroke, Badge |
| **Medium (Level 2)** | `--shadow-md` | `0 4px 12px rgba(0,0,0,0.12)`| Marker Popup, Card Event |
| **High (Level 3)** | `--shadow-lg` | `0 12px 24px rgba(0,0,0,0.18)`| Floating Search Bar, Bottom Sheet |
| **Highest (Level 4)**| `--shadow-xl` | `0 20px 32px rgba(0,0,0,0.25)`| Modal Dialog Form Pelaporan |

```css
:root {
  --shadow-sm: 0 2px 4px rgba(15, 23, 42, 0.08);
  --shadow-md: 0 4px 12px rgba(15, 23, 42, 0.12);
  --shadow-lg: 0 12px 24px rgba(15, 23, 42, 0.18);
  --shadow-xl: 0 20px 32px rgba(15, 23, 42, 0.25);
}
```

# 6. Shapes (Bentuk & Sudut)

Aplikasi ini menggunakan sudut melengkung modern (*smooth rounded corners*) agar tidak terkesan kaku.

- **Radius Pill (`9999px`):** Digunakan untuk Floating Search Bar, Filter Chip, Badge Skala Sound, dan FAB "Lapor Event".
- **Radius Card (`16px`):** Digunakan untuk Bottom Sheet, Popup Peta, dan Box Detail Event.
- **Radius Input (`10px`):** Digunakan untuk kolom input form pelaporan (Latitude, Longitude, Waktu).

```css
:root {
  --radius-sm: 6px;
  --radius-md: 10px;
  --radius-lg: 16px;
  --radius-pill: 9999px;
}
```

# 8. Do's and Don'ts (Boleh dan Tidak Boleh)

Berikut adalah panduan praktik terbaik (Do's) dan praktik yang harus dihindari (Don'ts) dalam mengimplementasikan antarmuka SoundHoregSafe:

###  DO (Rekomendasi Praktik Terbaik)

1. **Opasitas Transparan pada Radius Peta (20% – 30%)**  
   Gunakan warna *fill radius* yang transparan agar nama jalan, pemukiman, dan batas wilayah di bawah area bahaya/waspada tetap terlihat dan dapat dibaca warga dengan jelas.

2. **Warna Kontras Tinggi untuk Penggunaan Luar Ruangan (*Outdoor*)**  
   Gunakan warna penanda bahaya neon/vivid yang tajam (seperti Crimson Red `#dc2626`) agar indikator bahaya tetap dapat dibaca warga di bawah terik sinar matahari.

3. **Panel Melayang Ringkas (*Collapsible Bottom Sheet*)**  
   Sediakan tombol tutup/kecilkan (*collapse/dismiss*) pada panel detail event agar area peta tidak tertutup sepenuhnya dan ruang jelajah peta tetap luas.

4. **Indikator Loading Peta yang Jelas**  
   Tampilkan animasi *spinner* atau *skeleton UI* saat data titik event sedang dimuat dari backend server agar pengguna tahu sistem sedang bekerja.

5. **Form Pelaporan Lokasi yang Simpel (Klik Peta Langsung)**  
   Membuat fitur klik atau *drag marker* di peta untuk mengisi latitude dan longitude secara otomatis, sehingga pelapor tidak perlu memasukkan koordinat manual.

---

###  DON'T (Praktik yang Harus Dihindari)

1. **Warna Radius Peta Solid / Pekat (100% Opaque)**  
   Dilarang menutup area peta dengan warna solid tanpa transparansi karena akan menghalangi tulisan nama jalan dan membuat lokasi sekitar tidak terlihat.

2. **Warna Soft / Pastel untuk Indikator Peringatan**  
   Hindari warna merah atau kuning pastel yang samar-samar karena sulit terlihat saat pengguna mengakses web di layar smartphone outdoor.

3. **Pop-up / Modal Fullscreen Permanen**  
   Hindari menutup seluruh tampilan peta saat pengguna mengklik satu detail event, karena akan menghilangkan konteks geografis/lokasi di sekitar pengguna.

4. **Peta Kosong Tanpa Keterangan Status Loading**  
   Dilarang membiarkan tampilan peta polos tanpa petunjuk visual saat koneksi internet lambat atau server sedang memuat data titik event.

5. **Input Form Koordinat Ketik Manual**  
   Hindari meminta pelapor mengetik angka koordinat desimal (seperti `-6.754, 111.038`) secara manual yang berpotensi tinggi menghasilkan kesalahan input (*human error*).
